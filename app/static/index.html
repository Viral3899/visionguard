Configure local voice siren and optional Telegram security alerts

🔊 Voice Siren (TTS)

Uses offline Windows SAPI (pyttsx3). No internet required.

Siren triggers on: fire, smoke, violence, weapon, fight, assault, intrusion

📨 Telegram Security Alerts

Configure TELEGRAM_BOT_TOKEN and TELEGRAM_CHAT_ID in your private .env file, then enable Telegram on each camera. Only configured suspicious events with confidence strictly greater than 75% are sent. Events without a model confidence score are never sent.

Telegram: confirmed fire, smoke, weapons, trained violence/unusual activity at 50%+ model confidence. No routine-frame, proximity or loitering alerts.
